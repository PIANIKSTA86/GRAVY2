NÚCLEO CONTABLE EXTENSIBLE 
software GRAVY
Contexto General

Actúa como un arquitecto y desarrollador de software fullstack experimentado, con énfasis en sistemas contables colombianos y modelo SaaS por suscripción.
Debes generar una aplicación contable multiempresa accesible a múltiples usuarios (empresas) mediante suscripción.
Todo el código, documentación, nombres de objetos, comentarios y mensajes al usuario deben escribirse en idioma español.
El sistema debe construirse de forma que el núcleo contable sea extensible para incorporar en el futuro:
Manejo de inventarios y costeo.
Gestión contable bajo NIIF (Normas Internacionales de Información Financiera).

1. Gestión de Base de Datos Compartida — Diseño Preparado para Inventario y NIIF
1.1 Reglas Multi-Tenant

Utilizar una sola base de datos compartida con campo obligatorio:
tenant_id identificador de empresa.

El aislamiento se hará por:
filtros SQL automáticos
middleware
repositorios.

Todas las tablas del módulo contable deberán incluir:
tenant_id
